# 1413电源管理板软件设计方案

## 一、项目概述

### 1.1 系统架构

1413电源管理板系统由4个独立的STM32F4xx单片机组成，分别位于四个子项目目录中：

| 项目名称 | 设备数量 | 主要功能 |
|---------|---------|---------|
| DYGLB | 2个设备(TSGY/KF) | 控制28V电源上下电，电流限制 |
| DYGLB_U22 | 3个设备(GSDJ1/GSDJ2/DYGY) | 控制多路电源，环境监测 |
| DYGLB_U48 | 3个设备 | 多路电源控制与监控 |
| DYGLB_U57 | 3个设备 | 电源控制，IPMI协议通信 |

**核心工作原理**：每个单片机通过SPI接口接收上位机(FPGA)下发的控制指令，根据指令控制外部设备的电源开关，并将采集到的电压/电流数据上报给上位机。

## 二、系统功能分析

### 2.1 通信功能

#### 2.1.1 SPI通信 (与FPGA/上位机)

- **SPI1**: 用于与FPGA进行双向数据通信
  - 模式: 全双工，主模式
  - 数据位: 16位
  - 时钟: CPOL=High, CPHA=2Edge
  - 波特率: APB2时钟/16 (约10.5MHz)

- **通信协议**:
  - 上行数据包(单片机→FPGA):
    ```
    | 帧头(0x55AA) | 数据长度 | 设备0电压 | 设备0电流 | 设备1电压 | 设备1电流 | ... | 状态与告警 | 校验和 | 帧尾(0xACBC) |
    ```
  - 下行数据包(FPGA→单片机):
    ```
    | 帧头(0x55AA) | 数据长度 | 设备0限流 | 设备1限流 | ... | 状态与默认上电 | 校验和 | 帧尾(0xACBC) |
    ```

- **校验机制**: 累加校验 (dataHead + data_len + messageData + stuAndwarning)

#### 2.1.2 I2C通信 (EEPROM与传感器)

- **EEPROM (AT24C02)**:
  - 存储默认上电配置信息
  - I2C地址: 0xAE (8位写地址)
  - 支持页写入(8字节/页)

- **传感器 (根据项目不同)**:
  - 温度传感器: SD5075
  - 电压监测: LTC2990
  - 扩展I/O: AT9555, AT8591T

### 2.2 数据采集功能

#### 2.2.1 AD7606模数转换

- **功能**: 采集外部电压/电流模拟信号
- **通道数**: 8通道
- **通信**: SPI3 (从模式)
  - 模式: 全双工
  - 数据位: 16位
  - 波特率: APB1时钟/2 (42MHz)

- **数据处理**:
  - 滑动平均滤波 (N=10)
  - 校准补偿: `实际值 = k * 原始值 + b` (k,b存储在Flash 0x080E0000)

- **转换公式**:
  - 电压: `analog_data = (adc * 10*1000) * 4 / 32768` mV
  - 电流: `analog_data = (adc * 10*1000) / 32768 / 量程` mA

#### 2.2.2 外部中断触发

- **BUSY信号检测**: AD7606转换完成时BUSY引脚下降沿触发
- **EXTI0_IRQHandler**: 读取8通道ADC数据

### 2.3 电源控制功能

#### 2.3.1 设备开关控制

- **控制方式**: GPIO输出控制继电器/开关
- **控制对象** (以DYGLB为例):
  - TSGY: GPIO_Pin_7 (输出), GPIO_Pin_5 (告警输入)
  - KF: GPIO_Pin_9 (输出), GPIO_Pin_8 (告警输入)

- **控制逻辑**:
  ```
  收到开→继电器吸合→延时→检测首次开启标志
  收到关→继电器断开→复位首次开启标志
  ```

#### 2.3.2 限流设置 (AD5542 DAC)

- **功能**: 通过DAC输出限流参考电压到4001芯片
- **通信**: SPI2 (单线发送模式)
  - 数据位: 16位
  - 波特率: APB1时钟/4

- **转换公式**:
  ```
  TSGY: DAC输出 = (限流值/1000) * 0.5 * 26214
  KF:   DAC输出 = (限流值/1000) * 0.125 * 26214
  ```

- **4001芯片**: 硬件限流保护芯片，接收DAC输出作为参考

#### 2.3.3 自恢复功能

- **功能**: 设备开启后超过设定时间自动转为恒流模式
- **超时时间**: 1000ms (可配置)
- **触发条件**: `dev_Open_counter_time[i] > overTime`

### 2.4 定时与看门狗功能

#### 2.4.1 定时器

- **TIM2**: 毫秒级时间基准
  - 定时周期: 1ms
  - 用途: 系统运行时间计数

- **TIM3**: 设备开启时间计数
  - 定时周期: 1ms
  - 用途: 设备开启超时统计

#### 2.4.2 独立看门狗 (IWDG)

- **超时时间**: 约1.6秒 (预分频64, 重装载800)
- **作用**: 系统死机时自动复位

### 2.5 存储功能

#### 2.5.1 Flash存储

- **地址**: 0x080E0000
- **内容**: 校准参数 (k值和b值)
- **大小**: 13个float (52字节) * 2 (k和b)

#### 2.5.2 EEPROM存储

- **地址**: 0x00
- **内容**: 默认上电配置 (各设备开机状态)
- **操作**: I2C字节读写

### 3.2 主循环流程

```c
// main.c 主循环
while(1)
{
    // 1. 软件定时器处理
    softtimer_loop();
    
    // 2. 数据发送流程
    AD7606_StartConv();          // 触发ADC转换
    Alldata_sliding_average(0); // 滑动平均滤波
    AD7606Analog_data_Conversion(); // ADC值转换为实际物理量
    data_Packet_Creat();         // 构建发送数据包
    messageData_Send();          // SPI发送数据
    
    // 3. 数据接收处理
    ret = messageData_Recive();  // 接收上位机指令
    if(ret == 1)
    {
        operation_dev();        // 执行设备操作
        limitCurrent_Config();  // 配置限流值
        save_Default_Power();    // 保存默认上电配置
    }
    
    // 4. 自恢复时间处理
    selfRecoveTime(1000);        // 设备超时处理
    
    // 5. 喂狗
    IWDG_Feed();                // 独立看门狗喂狗
    
    delay_ms(1);                // 延时
}
```

| EXTI0_IRQHandler | AD7606数据读取 |
| TIM2_IRQHandler | 毫秒计数累加 |

## 四、通信协议详解

### 4.1 上行数据帧 (单片机→FPGA)

```c
typedef struct {
    uint16_t  dataHead;         // 0x55AA
    uint16_t  data_len;         // 3*DEVNUM*2 + 2
    uint16_t  messageData[DEVNUM*3]; // [设备号, 电压, 电流, ...]
    STUSIG_PACKED stuAndwarning; // 状态与告警
    uint16_t  sum;              // 校验和
    uint16_t  dataEnd;          // 0xACBC
} SEND_MESSAGE;
```

**状态与告警位定义**:
| 位 | 名称 | 说明 |
|---|------|------|
| bit0 | tsgy_stu | TSGY设备状态 |
| bit1 | kf_stu | KF设备状态 |
| bit4 | tsgy_default | TSGY默认上电 |
| bit5 | kf_default | KF默认上电 |
| bit8 | tsgy_warning | TSGY告警 |
| bit9 | kf_warning | KF告警 |

### 4.2 下行数据帧 (FPGA→单片机)

```c
typedef struct {
    uint16_t  dataHead;         // 0x55AA
    uint16_t  data_len;         // 3*DEVNUM*2 + 2
    uint16_t  messageData[DEVNUM*3]; // [设备号, 限流高8位, 限流低8位, ...]
    STUSIG_PACKED stuAndwarning; // 状态与默认上电配置
    uint16_t  sum;              // 校验和
    uint16_t  dataEnd;          // 0xACBC
} RECIVE_MESSAGE;
```

## 五、关键参数配置

### 5.1 系统时钟

- 主频: 168MHz (HSE 8MHz + PLL)
- APB1: 42MHz
- APB2: 84MHz

### 5.2 定时器配置

| 定时器 | 预分频 | 自动重装载 | 周期 |
|-------|--------|-----------|------|
| TIM2 | 84-1 | 1000-1 | 1ms |
| TIM3 | 8400-1 | 10-1 | 1ms |

### 5.3 SPI配置

| SPI | 角色 | 时钟极性 | 时钟相位 | 波特率 |
|-----|------|---------|---------|-------|
| SPI1 | Master | High | 2Edge | APB2/16 |
| SPI2 | Master | High | 2Edge | APB1/4 |
| SPI3 | Slave | High | 2Edge | APB1/2 |

## 六、错误处理机制

### 6.1 SPI通信错误

- **校验失败**: 连续3次接收错误则退出接收循环
- **超时处理**: 等待数据时设置超时计数器

### 6.2 I2C通信错误

- **超时回调**: I2C操作设置超时标志
- **EEPROM忙碌等待**: 等待 standby 状态

### 6.3 看门狗

- **超时复位**: 1.6秒未喂狗自动复位
- **喂狗位置**: 主循环中

## 七、版本差异说明

### 7.1 DYGLB vs DYGLB_U22/U48/U57

| 功能 | DYGLB | U22/U48/U57 |
|-----|-------|-------------|
| 设备数 | 2 | 3 |
| 外部传感器 | 无 | 温度/电压/IO扩展 |
| 通信协议 | 基础SPI | SPI + 扩展 |
| 数据采集 | AD7606 | AD7606 + 内部ADC |

### 7.2 U57特殊功能

- 支持IPMI协议
- 独立的spi_protocol模块
- 更多的外设驱动

## 九、总结

本系统是一个典型的嵌入式电源管理系统，通过SPI实现与上位机的双向通信，完成电源控制和数据采集任务。系统采用模块化设计，层次清晰，具有良好的可扩展性。

**核心特点**:
- 实时性强: 毫秒级控制周期
- 可靠性高: 看门狗保护 + 通信校验
- 精度高: 16位ADC + 16位DAC + 校准补偿
- 存储持久: EEPROM存储默认配置 + Flash存储校准参数
