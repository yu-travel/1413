一、芯片引脚
SPI 通信组：CS、SCLK、DIN、DOUT
1. CS片选
SPI 总线使能，只有CS=0时芯片才响应 SCLK/DIN/DOUT 通信
2. SCLK SPI 时钟
空闲默认低；上升沿锁存 DIN 输入，下降沿输出 DOUT 数据
3. DIN 主机发数据(高位 (MSB) 先行)
MCU 向 ADS1258 下发命令 + 寄存器配置数据
4. DOUT 芯片回传数据(高位先行)
ADS1258 向 MCU 返回24 位 ADC 采样值 + 状态字节、寄存器读数。
控制引脚：RESET (RST)、START、DRDY
1. RESET 复位
拉低至少2 个系统时钟周期再释放高电平
复位效果:
全部配置寄存器恢复出厂默认值；
清空数字滤波缓存，终止当前转换；
SPI 接口重置，通信异常时可硬件复位恢复。
2. START 转换启动
连续自动扫描（Auto-Scan）:
START 永久拉高：芯片循环扫描所有已选通道，每通道转换完成拉低 DRDY；
START 拉低：当前通道转换完成后停止，进入 Standby/Sleep 低功耗。
单次脉冲转换:
START 持续低，MCU 发「脉冲转换 SPI 命令」，每发一次仅转换 1 个通道；
也可用 GPIO 外接 START，软件控制启停。
3. DRDY数据就绪
硬件中断信号，告知 MCU当前通道 24bit 采样数据已稳定可读。
电平逻辑：
转换完成：DRDY=0；
SPI 读出数据的第一个 SCLK 下降沿，DRDY自动变回高；

二、命令字节格式（8bit，所有通信先发 1 字节命令）
命令字节结构：Bit7 Bit6 Bit5 | Bit4 | Bit3~0 = C2 C1 C0 | MUL | A3 A2 A1 A0
1.C [2:0]（命令码，高 3 位）
表格
C2 C1 C0	命令名称				功能说明
000 / 111	直接读通道数据 (Direct Read)	无前置命令，等待 DRDY 低直接移位读出；读完必须切换 CS 重置 SPI，否则无法发新命令
001		寄存器格式读通道数据 (RDATA)	带缓冲，数据不会被新转换覆盖，推荐工业使用；MUL 必须置 1
010		寄存器读 (RREG)			读取配置寄存器，A3~0 = 起始地址，MUL=1 可连续读多寄存器
011		寄存器写 (WREG)			写入配置寄存器，后跟 1 字节寄存器数据
100		单次脉冲转换 (PULSE)		START 引脚拉低时，发一次命令转换 1 个通道
110		软件复位 (RESET CMD)		寄存器恢复默认，无需操作 RST 硬件引脚
2.MUL 位 (Bit4)：多寄存器连续读写开关
MUL=0：仅读写单个指定地址寄存器
MUL=1：读写后地址自动 + 1，直到 09h (芯片 ID 寄存器) 停止
3.A3:0：寄存器起始地址
寄存器地址总表：
00h (CONFIG0)、01h (CONFIG1)、02h (MUXSCH)、03h (MUXD)、04h (MUXSG0)、05h (MUXSG1)、06h (SYSRED)、07h (GPIOC)、08h (GPIOD)、09h (ID)

三、三大通信操作完整流程流程 
1：寄存器写操作（WREG，C=011）：
CS 拉低，等待2.5t_CLK；
DIN 发送 8bit 命令：0 1 1 MUL A3 A2 A1 A0；
继续移位，DIN 发送 1 字节待写入寄存器数据；
全部移位完成后，CS 拉高至少2_t_CLK结束。
示例：写 CONFIG0 (00h)=0x0A → 命令字节 = 01100000 (0x60)，后发 0x0A
2：寄存器读操作（RREG，C=010）
CS 拉低
DIN 发命令0 1 0 MUL A3 A2 A1 A0
第 8 个 SCLK 下降沿开始，DOUT 输出寄存器数据（MUL=1 会连续输出多寄存器）
读完 CS 拉高
3：两种通道 ADC 数据读取（核心采集协议）
方式 A：直接读 Direct Read
Direct Read时序
等待DRDY=0（数据就绪）
CS 拉低，DIN 保持低 / 高任意（前 3bit 为 000/111 触发直读）
移位读出：
(1)Auto-Scan 模式：32bit=1 字节状态 + 3 字节 24bit ADC
(2)Fixed 固定通道：仅 24bit，无状态字节
限制：读完必须拉高 CS 重置 SPI，否则无法发送写 / 读寄存器命令；未及时读取会被下一轮转换覆盖数据
方式 B：寄存器格式读 RDATA（001）
RDATA带缓冲读时序
无需严格同步 DRDY，提前发送读命令
CS 拉低，DIN 发命令001 1 xxxx（MUL 必须 = 1，固定 0x30）
后续 SCLK 自动输出 32bit（1 状态 + 3 数据），数据存入硬件缓冲，新转换不会覆盖旧读数
优势：可连续多次读、无需频繁切换 CS
状态字节（32bit 读取首字节，8bit 定义）Bit7 (NEW)：1 = 数据未读取，0 = 已读
Bit6 (OVF)：输入超量程溢出标志
Bit5 (SUPPLY)：模拟电源低于 4.3V 告警
Bit4~0 (CHID)：当前采样通道编号（Auto-Scan 有效）ADC 数据格式后 3 字节为 24 位二进制补码，MSB 先行；
满量程：+1.06VREF → 0x7FFFFF；-1.06VREF → 0x80000
四、寄存器配置
1. CONFIG0 地址 00h，默认 0x0A（核心总控寄存器）
位布局：Bit7 (0) | Bit6 (SPIRST) | Bit5 (MUXMOD) | Bit4 (BYPAS) | Bit3 (CLKENB) | Bit2 (CHOP) | Bit1 (STAT) | Bit0 (0)
表格
位	名称	配置 0						配置 1							用途 & 配置场景
7	保留	必须固定 0					-							硬件固定，写入只能填 0
6	SPIRST	SCLK 空闲 4096 个系统时钟后 SPI 自动复位（默认）	256 个系统时钟超时复位					通信容易断连时置 1，快速恢复 SPI
5	MUXMOD	Auto-Scan 自动多通道循环扫描（默认）		Fixed 单通道固定模式					多通道巡检选 0；单通道高频采集选 1
4	BYPAS	多路输出直连 ADC 内部，无需外部运放		启用 MUXOUTP/MUXOUTN 外部调理电路			外部缓冲 / 滤波电路时置 1，内部直连通 0
3	CLKENB	关闭 CLKO 15.7MHz 时钟输出			开启时钟输出（默认）					需要给其他芯片提供时钟置 1，省电置 0
2	CHOP	关闭外部斩波（默认）				开启斩波，消除外部运放温漂偏移				高精度小信号采集置 1；读内部温度 / 电源 / 基准必须置 0
1	STAT	读取数据不返回状态字节				每次读 ADC 返回 1 字节状态 + 3 字节 24 位数据（默认）	需要通道 ID、溢出、电源告警必须置 1
0	保留	必须固定 0					-							固定写 0
常用配置示例
多通道、带状态、不开斩波、内部直连：0x0A（出厂默认）
高精度小信号斩波开启：0x0E
单通道固定模式、关闭时钟输出：0x28
2. CONFIG1 地址 01h，默认 0x83（速率、延时、偏置、休眠）
位布局：Bit7 (IDLMOD) | Bit6 (DLY2) | Bit5 (DLY1) | Bit4 (DLY0) | Bit3 (SBCS1) | Bit2 (SBCS0) | Bit1 (DRATE1) | Bit0 (DRATE0)
分段说明
1）Bit7 IDLMOD 空闲模式
0：Standby 待机，唤醒速度快
1：Sleep 睡眠（默认），功耗更低，唤醒延时更长
2）Bit6~4 DLY [2:0] 通道切换延时（Auto-Scan 专用）
通道切换后等待 N 个时钟再采样，适配外部 RC / 运放建立时间
表格
DLY 编码		延时周期					适用场景
000		0（无延时，默认）			内部直连、无外部电路
001~111		1/2/4/8/16/32/48 个 128/fCLK 周期	外部滤波大，需要长时间建立
3）Bit3~2 SBCS [1:0] 传感器偏置电流（断线检测）
00：关闭偏置（默认）
01：1.5μA 小电流
11：24μA 大电流（断线检测推荐）
原理：传感器断线时输入被拉到满量程，读取溢出判定开路；读内部监测寄存器必须关闭。
4）Bit1~0 DRATE [1:0] 滤波平均 / 采样速率（核心噪声速率权衡）
fCLK=16MHz 标准速率表：
表格
DRATE	Fixed 单通道		Auto 每通道	噪声 uVrms	适用
11	125kSPS			23.7kSPS	12		高速低精度
10	31.25kSPS		15.1kSPS	7.9		平衡
01	7.813kSPS		6.1kSPS		4.5		中高精度
00	1.953kSPS		1.8kSPS		2.8		极低噪声高精度
常用配置示例
默认睡眠、无延时、无偏置、高速：0x83
Standby 待机、16 周期延时、24μA 偏置、低速低噪：0x60
3. MUXSCH 地址 02h，默认 0x00（仅 Fixed 固定通道模式生效）
位布局：Bit7~4 (AINP [3:0]) | Bit3~0 (AINN [3:0])
AINP：ADC 差分正输入通道编号（0~15 对应 AIN0~AIN15）
AINN：ADC 差分负输入通道编号（0~15 对应 AIN0~AIN15）
配置规则
仅当 CONFIG0.MUXMOD=1（Fixed 模式）生效，Auto-Scan 下无效
单端采集：AINN 设为对应 AINCOM 参考电平通道
差分采集：AINP = 偶数、AINN = 同组奇数（如 AIN0 (0)、AIN1 (1) → 写入 0x01）
示例：差分通道 0（AIN0+,AIN1-）→ MUXSCH=0x01
4. MUXDIF 地址 03h，默认 0x00（Auto-Scan 差分通道选择）
8 位对应 DIFF7~DIFF0（Bit7=DIFF7，Bit0=DIFF0）
Bit=1：开启该差分对自动扫描；Bit=0：跳过
差分对应关系：
DIFF0 (AIN0/AIN1)、DIFF1 (AIN2/AIN3) … DIFF7 (AIN14/AIN15)
示例：只扫描 DIFF0、DIFF2 → 二进制 00000101 = 0x05
5. MUXSG0 地址 04h，默认 0xFF（Auto-Scan 单端 AIN0~AIN7）
8 位分别对应 AIN7 (Bit7) ~ AIN0 (Bit0)
Bit=1：开启该单端通道；0：跳过
默认 0xFF = 全部 0~7 单端通道开启；只开 AIN0 则写 0x01
6. MUXSG1 地址 05h，默认 0xFF（Auto-Scan 单端 AIN8~AIN15）
8 位对应 AIN15 (Bit7) ~ AIN8 (Bit0)
同理，只开启 AIN8：0x01；全部关闭：0x00
7. SYSRED 地址 06h，默认 0x00（Auto-Scan 内部监测通道开关）
位布局：Bit7 (0) | Bit6 (0) | Bit5 (REF) | Bit4 (GAIN) | Bit3 (TEMP) | Bit2 (VCC) | Bit1 (0) | Bit0 (OFFSET)
REF=1：扫描外部基准电压
GAIN=1：ADC 增益自校准读取
TEMP=1：片内温度读取
VCC=1：模拟电源 AVDD-AVSS 读取
OFFSET=1：ADC 输入短路偏移读取
注意：读取以上内部参数必须把 CONFIG0.CHOP 置 0，否则读数错误
示例：开启温度 + 电源监测 → Bit3=1 Bit2=1 → 0x0C
8. GPIOC 地址 07h，默认 0xFF（GPIO 方向配置）
Bit7~0 对应 GPIO7~GPIO0
Bit=1：GPIO 配置为输入（默认，禁止浮空）
Bit=0：GPIO 配置为输出
示例：GPIO0、GPIO1 设输出，其余输入 → 0xFC
9. GPIOD 地址 08h，默认 0x00（GPIO 电平寄存器）
Bit7~0 对应 GPIO7~GPIO0
输出模式：写入 1 = 高电平，0 = 低电平
输入模式：读取该位得到引脚当前电平
示例：GPIO0 输出高电平 → 写入 0x01
10. ID 地址 09h，只读寄存器（芯片 ID）
固定读出 0x8B，用于程序校验芯片是否为 ADS1258，不可写入

引脚协同工作示例：
若读完数据前下一轮转换完成，DRDY会先拉高 1 个CLK再重新拉低。
硬件初始化：RESET拉低复位，释放；配置晶振 / 外部时钟；
SPI 配置：拉低CS，通过 DIN 写入 CONFIG、MUX 通道选择、DRATE 速率寄存器；
启动转换：START 置高进入连续采集；
等待就绪：中断\轮询检测DRDY变低；
SPI 读数据：保持CS低，SCLK 移位，DOUT 输出状态 + 24bit 采样；
读完后DRDY自动恢复高，等待下一次转换就绪；
